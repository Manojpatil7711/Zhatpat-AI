TOOLS FOR EVERYDAY CREATION

Free browser-based image and video tools

Zhatpat AI brings practical creative tools together in one simple workspace. Use Image to Text OCR to extract printed text from photos and screenshots in English, Hindi or Marathi. OCR works best with clear, well-lit images and readable printed text; handwriting and mixed-language pages may need manual correction.

For portrait photos, the AI Background Remover uses a portrait-matting model to create a transparent PNG. It is designed for people and similar portrait subjects, not every kind of object. The Fast Object Eraser uses classical inpainting for small distractions, while AI Object Eraser uses a generative model to create a plausible fill. For photo quality, Photo Enhancement reduces some noise and compression artefacts with 4× upscaling, and AI Image Upscaler increases supported images by 2×. The Video Watermark Editor lets you manually select and mask areas in videos you own or have permission to edit.

These tools run in your browser where supported. Model files and software libraries may be downloaded from third-party services such as Hugging Face and public CDNs. Limits vary by tool and device. Check each tool page for model size, supported formats, file limits and known limitations before starting.

QUICK ANSWERS

Frequently asked questions

Are Zhatpat AI tools free to use?

The current tool collection is available without an account. File and model limits apply and may vary by tool.

Do I need to install an app?

No installation is required for the browser tools. Open a tool page in a modern browser and select your file.

Does my photo get uploaded?

The current image and video processing tools are designed to process selected files in your browser rather than upload them to a Zhatpat application server. Tool pages explain when third-party model or library downloads are used.

Why can the first AI run take longer?

Some tools need to download model files and prepare the inference engine the first time. Later use may be faster if your browser cache is available.

Can the Background Remover remove any object?

No. It uses portrait matting and works best with clear people or portrait subjects. It is not a universal object-segmentation model.

Can AI restore the exact original details?

No. Upscaling and generative fill can create plausible details, but they cannot guarantee recovery of information that is missing from the original file.

Which languages does Image to Text support?

The OCR tool currently offers English, Hindi and Marathi language selection. Results depend on image quality and printed text clarity.
