  • Output is exactly 2× the original width and height. This beta currently supports images up to 512 × 512 pixels.
  • The first run downloads the AI model; speed depends on your phone, browser and available memory.
What this beta can and cannot do

This tool uses Clark Swin2SR Lightweight ×2, an Apache 2.0 model. It performs fixed 2× super-resolution; it does not create a 4× result or guarantee recovery of details missing from a severely blurred source. The model reports stronger results on several realistic screenshot degradations, but quality varies by image and clean-image benchmark results are not uniformly best-in-class. Review the output before use.

Your selected image is processed locally in your browser and is not sent to a Zhatpat application server. The compressed model (about 1.7 MB) and ONNX Runtime Web are downloaded from Hugging Face and jsDelivr. Model: Clark Swin2SR ×2. Runtime: ONNX Runtime Web. See model licence and attribution.
