About this AI beta

This tool uses MI-GAN (Mobile Inpainting GAN) to generate plausible replacement pixels inside the marked region. It does not recover the exact hidden background. Review the result carefully, especially around faces, text, logos and detailed patterns. Input is resized to a maximum of 1 megapixel for device-memory safety. The image is processed in your browser and is not sent to a Zhatpat application server. The model and ONNX Runtime are downloaded from Hugging Face and jsDelivr.

Model: MI-GAN ONNX model and model card. Runtime: ONNX Runtime Web. Model licence: MIT; see attribution and licence.
