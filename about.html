ABOUT THE PROJECT

Useful creative tools, without the clutter.

Zhatpat AI is an independent browser-based tool project focused on making everyday image, text and video tasks easier to access. The collection currently includes OCR for English, Hindi and Marathi, portrait background removal, two approaches to object cleanup, photo enhancement, image upscaling and video watermark masking.

What guides the project

  • Clear capabilities: each tool should explain what it can and cannot do.
  • Browser-first processing: supported tools process selected files on the user's device; model and library downloads may come from third-party hosts.
  • Practical limits: file sizes, supported formats and device requirements should be visible before processing.
  • Quality before quantity: tools and features should be released only when their core workflow is ready.

Current stage

Zhatpat AI is an evolving project. AI outputs can vary by input and device, and generative tools may create plausible rather than historically exact details. Please review results before relying on or sharing them.

For questions, see the Contact page, and read how files and website information are handled in the Privacy information.
